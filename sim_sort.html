สื่อโต้ตอบ บทที่ 11 — Bubble Sort และ Stack/Queue

GNR 1007 เตรียมสอบ กว. Computer Programming | สาขาวิศวกรรมคอมพิวเตอร์ มหาวิทยาลัยรามคำแหง

ทำไมบทนี้สำคัญ

Data Structure พื้นฐาน 3 ตัวที่ออกสอบบ่อย: Bubble Sort (อัลกอริทึมเรียงลำดับที่เข้าใจง่ายที่สุด), Stack (LIFO เข้าหลังออกก่อน) และ Queue (FIFO เข้าก่อนออกก่อน) ลองกดทีละขั้นเพื่อดูการทำงานจริง

น้ำหนักข้อสอบกลาง
สอนช่วงที่13

Bubble Sort — เรียงแพนเค้ก

เปรียบเทียบ: 0
สลับ: 0
รอบ (pass): 0
✔ เรียงเสร็จแล้ว!
for i = 0 ถึง n-2
  for j = 0 ถึง n-2-i
    if arr[j] > arr[j+1]
      สลับ arr[j] กับ arr[j+1]
กด "ทีละขั้น" เพื่อเริ่มดู
จุดหลอก กว.: Bubble Sort เปรียบเทียบคู่ที่อยู่ติดกันเท่านั้น (arr[j] กับ arr[j+1]) และสลับเมื่อลำดับผิด ทำให้ค่าที่มากที่สุดค่อยๆ "ลอย" ไปอยู่ท้ายอาร์เรย์ทีละรอบ เหมือนฟองอากาศลอยขึ้น — จำนวนรอบสูงสุดคือ n-1 รอบ (n = จำนวนสมาชิก)

Stack (LIFO) และ Queue (FIFO)

📚 Stack — เข้าหลังออกก่อน (LIFO)

Stack ว่าง — กด Push เพื่อเริ่ม

🚶 Queue — เข้าก่อนออกก่อน (FIFO)

Queue ว่าง — กด Enqueue เพื่อเริ่ม
จุดหลอก กว.: Stack (LIFO) เหมือนกองจาน — หยิบจานแผ่นบนสุดออกก่อนเสมอ (เช่น การกด Undo, การเรียกฟังก์ชันซ้อนกัน) ส่วน Queue (FIFO) เหมือนแถวต่อคิว — คนที่มาก่อนได้ออกก่อน (เช่น คิวพิมพ์เอกสาร) ข้อสอบมักสลับให้ตอบผิดระหว่างสองแนวคิดนี้
