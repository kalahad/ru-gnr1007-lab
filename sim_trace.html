โจทย์ "จงหาผลลัพธ์การทำงานของโค้ด" คือรูปแบบข้อสอบที่พบมากที่สุดในหมวด Computer Programming เทคนิคที่ใช้ทำคะแนนคือ "ตีตารางทดค่า" — จดค่าตัวแปรทุกครั้งที่เปลี่ยน ทีละบรรทัด วางโค้ด C ด้านล่างแล้วกด "แปลงเป็นขั้นตอน" เพื่อดูตารางทดค่าอัตโนมัติ พร้อมไฮไลต์บรรทัดที่กำลังทำงาน

จุดหลอก กว.: Prefix (++x) กับ Postfix (x++)
y = x++; → นำค่า เดิมของ x ไปใช้ก่อน แล้วค่อยเพิ่ม x ทีหลัง (y ได้ค่าเก่า)
y = ++x; → เพิ่มค่า x ก่อน แล้วนำค่าใหม่ไปใช้ (y ได้ค่าใหม่)
ลองพิมพ์โค้ดตัวอย่าง "Prefix vs Postfix" ด้านบนแล้วดูตารางทดค่าเปรียบเทียบ
ข้อจำกัดของเครื่องมือนี้ (เพื่อความชัดเจนในการสอน): รองรับตัวแปรชนิด int/float/char ในขอบเขตเดียว (ไม่มี scope ซ้อนแยกชื่อซ้ำ), เงื่อนไข if/else, ลูป for/while/do-while, printf อย่างง่าย (%d %f %c) — ยังไม่รองรับอาร์เรย์ ฟังก์ชัน หรือ struct (มีสื่อแยกต่างหากสำหรับอาร์เรย์ในบทที่ 7)
