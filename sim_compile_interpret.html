สื่อโต้ตอบ บทที่ 2 — โรงงานแปลภาษา (Compiler vs Interpreter)

GNR 1007 เตรียมสอบ กว. Computer Programming | สาขาวิศวกรรมคอมพิวเตอร์ มหาวิทยาลัยรามคำแหง

ทำไมบทนี้สำคัญ

Compiler และ Interpreter ต่างก็ "แปลภาษาโปรแกรม" ให้คอมพิวเตอร์เข้าใจ แต่แปลคนละจังหวะกัน — Compiler แปลทั้งโปรแกรมก่อนแล้วค่อยรัน ส่วน Interpreter แปลทีละบรรทัดแล้วรันทันที ลองกดรันโปรแกรมจำลองด้านล่างเทียบกันสด ๆ ทั้ง 2 แบบ

วิธีแปลแปลทั้งโปรแกรมก่อน สร้างไฟล์ execute (.exe)แปล + รันทีละบรรทัด/คำสั่ง
ถ้ามี error กลางโปรแกรมไม่รันแม้แต่บรรทัดเดียว จนกว่าจะแก้ errorรันบรรทัดก่อนหน้าไปแล้ว ก่อนหยุดที่บรรทัด error
ความเร็วตอนรันเร็วกว่า (แปลไว้ล่วงหน้าแล้ว)ช้ากว่า (แปลใหม่ทุกครั้งที่รัน)
ตัวอย่างภาษาC, C++ (gcc/g++)Python, JavaScript (มักใช้)
จุดหลอก กว.: ข้อสอบชอบถามว่า "ถ้าโปรแกรมมี error ที่บรรทัดกลาง ๆ แบบไหนจะเห็นผลลัพธ์บางส่วนก่อนเจอ error" — คำตอบคือ Interpreter (เพราะรันไปทีละบรรทัดจนกว่าจะชนบรรทัดที่ผิด) ส่วน Compiler จะไม่แสดงผลอะไรเลยถ้ามี error เพราะตรวจสอบทั้งโปรแกรมเสร็จก่อนจึงจะเริ่มรัน — ภาษา C ที่ใช้สอบ กว. เป็นภาษาที่ใช้ Compiler (gcc) เสมอ
