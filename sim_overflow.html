ตัวแปรแต่ละชนิดเก็บค่าได้ในช่วงจำกัดตามจำนวนบิต เมื่อบวกจนเกินค่าสูงสุด ค่าจะ "วนกลับ" ไปเป็นค่าต่ำสุดทันที (ไม่ error) ข้อสอบ กว. ชอบถามค่าสูงสุด/ต่ำสุดของ char และผลลัพธ์เมื่อ overflow ลองกดปุ่มเพิ่มค่าไปเรื่อยๆ แล้วสังเกตตัวเลขและบิตด้านล่าง

ตารางชนิดข้อมูลจำนวนเต็มที่ออกสอบบ่อย

ชนิดขนาดช่วงค่า
char (signed)1 byte (8 bit)-128 ถึง 127
unsigned char1 byte (8 bit)0 ถึง 255
int (signed, ทั่วไป)4 byte (32 bit)-2,147,483,648 ถึง 2,147,483,647
unsigned int4 byte (32 bit)0 ถึง 4,294,967,295
จุดหลอก กว.: char เก็บค่าสูงสุดได้ 127 ไม่ใช่ 128 เพราะ 1 บิต (บิตซ้ายสุด) ถูกใช้เป็น "บิตเครื่องหมาย" (Sign Bit) ทำให้เหลือใช้แทนขนาดจริง 7 บิต (2⁷ = 128 ค่า แบ่งเป็นบวก 0-127 และลบ -1 ถึง -128) — ห้ามสับสนกับ unsigned char ที่ไม่มีบิตเครื่องหมายจึงเก็บได้ถึง 255
