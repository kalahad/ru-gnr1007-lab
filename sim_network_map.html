สื่อโต้ตอบ บทที่ 1 — แผนที่เครือข่าย (LAN / MAN / WAN)

GNR 1007 เตรียมสอบ กว. Computer Programming | สาขาวิศวกรรมคอมพิวเตอร์ มหาวิทยาลัยรามคำแหง

ทำไมบทนี้สำคัญ

เครือข่ายคอมพิวเตอร์แบ่งตาม "ขนาดพื้นที่ทางภูมิศาสตร์ที่ครอบคลุม" ไม่ใช่จำนวนเครื่อง — นี่คือจุดหลอกอันดับหนึ่งของบทนี้ ลองไล่ภารกิจจัดหมวดหมู่ด้านล่าง แล้วดูว่าคุณจะแยก LAN, MAN, WAN ได้แม่นแค่ไหน

น้ำหนักข้อสอบสูง
เรียนวันที่1

3 ระดับของเครือข่าย — เล็กไปใหญ่

LAN

Local Area Network

พื้นที่จำกัด: ห้อง, อาคาร, องค์กรเดียว (ต่อให้มีหลายอาคารในรั้วเดียวกัน)

MAN

Metropolitan Area Network

ระดับเมือง: เชื่อมหลายสาขา/หลายองค์กรในเมืองเดียวกัน

WAN

Wide Area Network

ระดับประเทศ/โลก: อินเทอร์เน็ต, เชื่อมข้ามประเทศ

ภารกิจ: จัดหมวดหมู่เครือข่าย

สถานการณ์ 1 / 10 ถูก 0 ข้อ
กำลังโหลด...

รอบโบนัส: อุปกรณ์นี้เป็น Input, Process หรือ Output?

คอมพิวเตอร์ทำงานเป็น 3 ขั้นเสมอ: รับข้อมูล (Input) → ประมวลผล (Process) → แสดงผล (Output)

ประเภทพื้นที่ครอบคลุมตัวอย่าง
LANห้อง / อาคาร / องค์กรเดียวเครือข่ายในห้องแล็บ, Wi-Fi บ้าน, มหาวิทยาลัยเดียว
MANระดับเมืองเชื่อมสาขาธนาคารทั่วกรุงเทพฯ, เครือข่ายเคเบิลทีวีในเมือง
WANระดับประเทศ / โลกอินเทอร์เน็ต, เครือข่าย ATM ทั่วประเทศ, บริษัทข้ามชาติ
จุดหลอก กว.: การแบ่ง LAN/MAN/WAN ดูที่ ขนาดพื้นที่ทางภูมิศาสตร์ เท่านั้น ไม่เกี่ยวกับจำนวนเครื่อง — เครือข่าย 200 เครื่องในตึกเดียวกันยังเป็น LAN ส่วนเครือข่าย 3 เครื่องที่เชื่อมข้ามประเทศคือ WAN และข้อสอบชอบสลับ MAN กับ WAN โดยเฉพาะโจทย์ "หลายสาขาในเมืองเดียวกัน" (MAN ไม่ใช่ WAN)

ทดสอบความเข้าใจ

ใส่ seed เดียวกันเพื่อได้ชุดโจทย์เดิม (เหมาะเวลาเฉลยหน้าชั้น)

โหมดท้าทาย — จับเวลา 1.8 นาที/ข้อ (แบบสอบ กว.)
