สื่อโต้ตอบ บทที่ 7 — ขบวนรถไฟอาร์เรย์ (Array)

GNR 1007 เตรียมสอบ กว. Computer Programming | สาขาวิศวกรรมคอมพิวเตอร์ มหาวิทยาลัยรามคำแหง

ทำไมบทนี้สำคัญ

อาร์เรย์คือขบวนรถไฟที่แต่ละตู้เก็บค่าหนึ่งค่า และมี "หมายเลขตู้" (index) กำกับ โดย เริ่มนับที่ 0 เสมอ — ข้อสอบ กว. ชอบถามผลลัพธ์เมื่อเข้าถึง index ที่ไม่มีอยู่จริง (Out of Bounds) ลองพิมพ์ index แล้วดูว่าเกิดอะไรขึ้น

น้ำหนักข้อสอบกลาง
สอนช่วงที่7

สร้างขบวนรถไฟของคุณ

พิมพ์ index แล้วกด "เข้าถึงตู้นี้" — ลองพิมพ์เลขที่เกินขบวนดูว่าเกิดอะไรขึ้น!

ตารางสรุป

คุณสมบัติค่า
ขนาดอาร์เรย์ (n)-
Index แรกสุด0
Index สุดท้าย (ถูกต้อง)-
Index ที่ทำให้เกิด Out of Bounds ทันที-
จุดหลอก กว.: อาร์เรย์ขนาด n ช่อง จะมี index ตั้งแต่ 0 ถึง n-1 เท่านั้น (ไม่ใช่ 1 ถึง n) เช่น int arr[6] มี index ที่ใช้ได้คือ 0-5 หากเขียน arr[6] คือ index ที่ 7 ซึ่งไม่มีจริง เป็น "Out of Bounds" — ภาษา C จะไม่แจ้ง error ให้ทันทีแต่จะเกิดพฤติกรรมที่ไม่นิยาม (Undefined Behavior) ซึ่งอันตรายกว่าโปรแกรมพัง เพราะอาจให้ค่าขยะหรือทำโปรแกรมล่มภายหลัง

โบนัส: อาร์เรย์ 2 มิติ (เมทริกซ์ที่นั่ง)

อาร์เรย์ 2 มิติเหมือนผังที่นั่ง ต้องระบุ 2 ตัวเลข: แถว (row) และ คอลัมน์ (column) คลิกที่ช่องเพื่อดู index หรือพิมพ์ในช่องด้านล่างเพื่อทดสอบ index ที่ไม่มีอยู่จริง

เมทริกซ์นี้มี 3 แถว (0-2) และ 4 คอลัมน์ (0-3)
