สื่อโต้ตอบ บทที่ 4 — ลำดับการคำนวณ (Operator Precedence)

GNR 1007 เตรียมสอบ กว. Computer Programming | สาขาวิศวกรรมคอมพิวเตอร์ มหาวิทยาลัยรามคำแหง

ทำไมบทนี้สำคัญ

ข้อสอบ กว. ชอบออกโจทย์ "คำนวณผลลัพธ์" ที่ต้องรู้ลำดับความสำคัญของเครื่องหมาย (Precedence) ให้แม่น มิฉะนั้นจะคำนวณผิดทั้งที่บวกลบคูณหารถูกทุกขั้นตอน พิมพ์นิพจน์ภาษา C ด้านล่างแล้วกด "คำนวณทีละขั้น" เพื่อดูว่าเครื่องคิดส่วนไหนก่อน-หลัง

ลำดับความสำคัญของเครื่องหมาย (สูง → ต่ำ)

ลำดับเครื่องหมายทิศทางการคำนวณเมื่อลำดับเท่ากัน
1 (สูงสุด)( ) วงเล็บในสุดก่อน
2+x, -x (unary บวก/ลบหน้าตัวเลข)ขวาไปซ้าย
3* / % (คูณ หาร มอด)ซ้ายไปขวา
4 (ต่ำสุด)+ - (บวก ลบ)ซ้ายไปขวา

ลองคำนวณเอง

0 / 0
จุดหลอก กว.: เมื่อเครื่องหมายมีลำดับเท่ากัน (เช่น * / % ด้วยกัน หรือ + - ด้วยกัน) ต้องคำนวณ จากซ้ายไปขวา เท่านั้น ตัวอย่างข้อสอบยอดฮิต: 20 / 4 * 2 หลายคนคิดว่า * ต้องทำก่อนได้ 20/(4*2)=2.5 ซึ่งผิด — คำตอบที่ถูกคือ (20/4)*2 = 10 เพราะหารมาก่อนตามลำดับซ้าย-ขวา และการหารจำนวนเต็ม (int/int) ใน C จะตัดเศษทิ้งเสมอ (ไม่ปัดเศษ)
